# Tài liệu giới thiệu và demo

| Đường dẫn | Nội dung |
|---|---|
| `media/LNTT (1).mp4` | Video demo của nhóm |
| `masterone-intro/` | Các bản video giới thiệu MasterOne (`masterone-intro*.mp4`) và phụ đề tiếng Việt (`*.vi.srt`); chưa được Git theo dõi |
| `masterone-intro/source/` | Nguồn dựng video: kịch bản `script.json`, trang `video.html`, `render.mjs`, `gen_audio.py`, `music.py`, thư mục `story/`, `teaser/`, `combined/` |

Slide thuyết trình (`pitch_deck.pptx`) chưa có trong repo. Nội dung nên bám [docs/PRODUCT_REQUIREMENTS.md](../docs/PRODUCT_REQUIREMENTS.md) (bài toán, giải pháp, phạm vi), [ARCHITECTURE.md](../ARCHITECTURE.md) (kiến trúc), [docs/EVALUATION.md](../docs/EVALUATION.md) (số đo và giới hạn) và luồng demo ở [docs/USER_GUIDE.md](../docs/USER_GUIDE.md); dùng chế độ **Demo sản phẩm** để quay màn hình.
