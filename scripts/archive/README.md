# Script lịch sử

Các file này được chuyển từ thư mục gốc vào ngày 16/10/2026 vì không có
tham chiếu từ ứng dụng, CI hoặc các script đang dùng:

- `apply_refactor.py`, `refactor.py`, `refactor_service.py`: script ghi lại
  mã nguồn backend trong những đợt refactor trước.
- `temp_stand.py`: bản thử nghiệm chuẩn hóa dữ liệu độc lập.
- `test_gemini.py`: probe thủ công chứa đường dẫn tuyệt đối của máy cũ.

Giữ nguyên nội dung để tham khảo và khôi phục. Không cần chạy chúng để
khởi động, build hoặc kiểm thử hệ thống. Các script refactor có thao tác
ghi đè mã nguồn khi thực thi.
